# Simple Java Spring REST App

A full-stack Spring Boot REST application for managing customers, products, orders, and product-order relationships. This project serves as a simple e-commerce backend and client interface with CRUD functionality and a clean UI for managing data.

---

## 📦 Features

- 🧍 Customer Management (Create, Edit, Delete)
- 📦 Product Management with descriptions and prices
- 📝 Order Management with status tracking
- 🔗 Product-Order linking with quantity and pricing
- 🌐 REST API-based communication between client and backend

---

## 🧰 Technologies Used

| Layer | Tech |
|------|------|
| Backend | Java, Spring Boot |
| Frontend | HTML/CSS/JS|
| Build Tool | Maven |
| Database | H2 |
